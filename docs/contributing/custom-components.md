# Custom Components

These components can be used directly in Markdown pages.

| Component | Use |
| --- | --- |
| `<SectionLinks />` | On section `index.md` pages, lists child pages (and sibling sections) from the sidebar |
| `<FPBadge type="green" text="Latest" />` | Inline status badge; `type` can be `green`, `yellow`, `red`, `purple`, or `gray` |
| `<LatestRelease />` | Inline link that shows the current Fortnite Porting GitHub release tag |
