# Locating Blender

The method to locate your Blender executable depends on where you downloaded Blender from.

## blender.org

### From installer

**Default installation:** `C:\Program Files\Blender Foundation\Blender 5.x\blender.exe`

If Blender is not found there, follow these steps:

1. Right-click the shortcut on your desktop or in Windows Search / Start menu
2. Select **Open file location**
3. Repeat if you used a Start menu or Windows Search shortcut

<video controls src="/blender/locating-blender/regular.mp4"></video>

### Portable Installation (.zip)

It's the `blender.exe` inside the folder you extracted this zip into. If you cannot find it, that is on you.

## Steam

**Default installation:** `C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe`

If Blender is not found there, follow these steps:

1. Open Steam and go to your library
2. Right-click **Blender**
3. **Manage** -> **Browse local files**

<video controls src="/blender/locating-blender/steam.mp4"></video>

## Microsoft Store

If you installed Blender through the Microsoft Store, this will not work for you, please install Blender from the official [website](https://blender.org/download)
