# Installing the Plugin

## Syncing the Plugin

Syncing your Fortnite Porting application is required to use Fortnite Porting.

1. Make sure all Blender processes are closed. Syncing will not work if Blender is open.
2. In Fortnite Porting, navigate to the **Plugin** tab under Settings.
3. Press the **Add Version** button at the top right of the window. This opens a File Explorer window, locate your `blender.exe` here.
4. Navigate to where your `blender.exe` is located. If you aren't sure where your Blender is located, follow the guide at [Locating Blender](/blender/locating-blender)
5. Select your `blender.exe` and wait for Fortnite Porting's sync confirmation. Your Blender installation should be listed with a <FPBadge type="green" text="Latest" /> banner indicating latest.
6. All done! You will **not** need to enable the addon in Blender. Fortnite Porting V4 automatically enables it for you.

## Updating the Plugin

You may not need to update your Blender plugin every app update, but it is **highly recommended** to check your plugin every update. Not updating can cause issues or prevent new features from working as intended.

1. Ensure Blender is closed, then open the **Plugin** tab in Fortnite Porting's Settings.
2. Verify an update is available. If there is an update, your plugin should have a <FPBadge type="yellow" text="Update Available" /> banner
3. Select the **Sync** button at the top right of the window. On success, you should see a confirmation at the top.
4. Once syncing is complete, you are set, Fortnite Porting's plugin should be up to date.

## Removing the Plugin

1. Ensure all Blender processes are closed and navigate to the Fortnite Porting **Plugin** tab under Settings.
2. Select the **X** on the right side of the Blender version you want to unsync.
3. Blender and Fortnite Porting are no longer connected.
